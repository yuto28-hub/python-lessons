# 課題5: Gmail API でメールを送る

作業日: 2026年10月7日

## やったこと

指定した宛先にメールを1通送るスクリプトを作成した。

- 本体: `4-3-2/課題5/gmail_send.py`
- API: Gmail API v1（`users.messages.send`）
- スコープ: `https://www.googleapis.com/auth/gmail.send`
- 認証: OAuth 2.0（課題1で作った `credentials.json` を再利用）
- 追加ライブラリはなし。課題1と同じ `google-api-python-client` 一式を使う

## 使い方

```bash
python3 gmail_send.py 宛先メール "件名" "本文"
```

今回の実行は次のとおり。

```bash
python3 gmail_send.py sw.my.28@gmail.com "課題5" "Gmail API から送りました。"
```

初回だけブラウザが開き、送信の許可を求める。2回目以降は開かない。

## 設計で判断したこと

**1. 権限は送信だけにした**

`gmail.send` はメールを送ることしかできない。受信箱の閲覧も削除もできない。課題1の `drive.file`、課題3の `meetings.space.created` と同じく、必要な範囲だけに絞った。

**2. トークンを別ファイルにした**

課題1・2のスコープは `drive.file`、課題3は `meetings.space.created`、課題5は `gmail.send` で、どれも違う。同じ `token.json` を使い回すと、先に作った課題の認証がやり直しになる。

| ファイル | 用途 | スコープ |
|---------|------|---------|
| `token.json` | 課題1（Drive）・課題2（Docs） | `drive.file` |
| `token_meet.json` | 課題3（Meet） | `meetings.space.created` |
| `token_gmail.json` | 課題5（Gmail） | `gmail.send` |

3つとも `~/.config/gdrive/` にあり、権限は `600`。Git には入らない。

**3. 差出人は指定しない**

メールの `From` は付けない。Gmail が、ブラウザで許可したアカウントを差出人にする。別のアドレスを名乗れない。

本文は `EmailMessage` で組み立て、Gmail が求める URL-safe Base64 にして `raw` として送る。`userId` は `me`（許可した本人）を使う。

## 事前準備

Google Cloud は課題1と同じプロジェクト（My First Project）を使った。ライブラリで **Gmail API** を有効にするだけで、OAuth クライアントの作り直しは不要だった。

有効化に使ったページ:

```text
https://console.cloud.google.com/apis/library/gmail.googleapis.com?project=silken-network-507121-q2
```

## 実行結果

送信に成功し、受信箱にも届いた。

```text
【課題5】Gmail でメールを送る
宛先 : sw.my.28@gmail.com
件名 : 課題5
本文 : Gmail API から送りました。
送信しました
メッセージID : 1a113193468b6f6d
```

差出人は、ブラウザで許可した Google アカウント。認証情報は `~/.config/gdrive/token_gmail.json` に保存された。届いたことの確認は、受信箱を API で読んだのではなく、自分でメールを開いて見た。このスコープでは受信箱を読めない。
